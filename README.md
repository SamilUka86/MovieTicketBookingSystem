# 🎬 Movie Ticket Booking System

A feature-rich, console-based **Movie Ticket Booking System** written in **Java**. The application provides distinct access modes for **Developers** (Admin) and **Customers**, allowing seamless movie management, seat allocation, ticket booking, and cancellation.

---

## 🚀 Features

### 👨‍💻 Developer Mode (Admin)
- **Authentication**: Secured with developer passcode.
- **Movie Management**: Add, update, and remove movies, showtimes, and ticket prices.
- **Theater & Seat Configuration**: Configure screen layouts and seating availability.
- **Booking Overview**: View total bookings, revenue reports, and customer transactions.

### 👤 Customer Mode
- **Browse Movies**: View available movies, genres, ratings, and show timings.
- **Interactive Seat Selection**: Choose preferred seats dynamically.
- **Ticket Booking & Confirmation**: Instantly book tickets and generate summary receipts.
- **Booking Cancellation**: Cancel existing bookings and update seat availability.

---

## ⚙️ How to Run

1. **Clone or Download the Repository**:
   ```bash
   git clone https://github.com/SamilUka86/Movie-Ticket-Booking-System.git
   cd Movie-Ticket-Booking-System
   ```

2. **Compile the Java Program**:
   ```bash
   javac MovieTicketBooking.java
   ```

3. **Run the Application**:
   ```bash
   java Main
   ```

---

## 📌 Usage Instructions

- Select `1` for **Developer Mode**.
- Select `2` for **Customer Mode** to view movies and book tickets.
- Select `3` to **Exit** the application.
